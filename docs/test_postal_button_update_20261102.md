親 `対象請求書作成2026` を82→90ステップへ変更した。

- 請求年度が2027のとき、現在の対象レコードを巡回する既存ループ内で、各会員の `新請求パターン更新` を先に実行する。
- 更新結果が空なら請求書を作成せず、既存の結果集計へ返す。本人残額が負なら精算確認、それ以外は要確認。
- 更新後のポインタを子へ渡す。全正会員を検索する `新請求パターン全更新` は呼ばない。
- 2027年以外は既存経路を維持。既存82ステップは変更せず8ステップを追加。子・フィールド・レイアウトは今回変更していない。

保存後の90ステップを読戻し、計算式・参照を予定XMLと照合し一致。[テスト版XML](fm_settings_20261102/対象請求書作成2026-update-before-create-test.xml) に保存した。接尾辞なしの親XMLは現行本番の82ステップ版のまま。
