## 2. 二重控除を防ぐ前提

既存の計算は次のとおり。

```filemaker
次年度紹介割引 = 次年度基本年会費 / 12 * 紹介者数_会員毎
次年度請求分_New = 次年度基本年会費 - 次年度入金計 - 次年度紹介割引
```

請求パターン生成に渡す本人年会費は、すでに紹介割引を差し引いた `次年度請求分_New`。関連先 `年会費詳細2026::年会費額` も割引後の金額になる。

今回追加するのは明細の表示。**`請求金額合計` から紹介割引を再度引かない。** 割引前の表示額だけ `年会費額 + 紹介割引額` で復元し、合計には既存の `請求金額合計` をそのまま使用する。この復元額は既納入分の調整後であり、常に基本年会費と等しいわけではない。
